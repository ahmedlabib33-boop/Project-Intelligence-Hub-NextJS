## Contractual answer template

### Direct conclusion

State the answer in plain language and label it `SUPPORTED`, `PARTLY SUPPORTED`, `NOT YET PROVEN`, `UNSUPPORTED` or `CONFLICTING`.

### Governing provisions

| Priority | Source | Clause/page | Verified wording or controlled paraphrase | Effect |
|---:|---|---|---|---|

### Evidence

| Record | Date/revision | What it proves | What it does not prove | Status |
|---|---|---|---|---|

### Schedule assessment

Include model version, data date, integrity status, before/after finish, float, path and limitations.

### Engineer view and next action

State the neutral procedural step, required issuer, recipient, information and response deadline.

## Management dashboard controls

Every KPI and visual must show:

- Project ID
- Reporting cut-off/data date
- Dataset version
- Status and confidence
- Source reference
- Whether the value is technical, claimed, assessed or determined
